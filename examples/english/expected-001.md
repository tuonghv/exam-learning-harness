Explanation

This sentence uses the first conditional to describe a possible future situation.

Structure:

If + present simple, will + base verb

* If I have enough time tomorrow, I will help you.
* B. had: past simple, not appropriate for the intended first conditional.
* C. will have: normally, the present simple is used in the if-clause of this conditional.
* D. would have: does not fit the intended conditional structure.
