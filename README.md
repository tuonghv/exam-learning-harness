# exam-learning-harness

Checkable input/expected-output examples (few-shot and eval) for Vietnamese exam subjects, plus a
stdlib Python engine (`src/exam_engine`, entry `python3 -I scripts/exam.py`) to solve, verify, report and score them.

- Architecture, components, flow, invariants: `docs/guide/architecture.md`
- Example format standard: `examples/FORMAT.md`
- Requirements: `docs/req/`; design: `docs/design/`; guides: `docs/guide/`
