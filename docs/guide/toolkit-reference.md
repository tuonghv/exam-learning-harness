## Commands

- `exam.py run-stats stats DIR | compare A B | trend | backfill DIR...` (TASK-056): run metrics from result.json + run.log; history `plans/run-history.jsonl` (`--history`; legacy `reports/` and `results/run-history.jsonl` still read), appended by `solve --real` or `solve --history`. `solve` without `--out` writes a plan run `plans/<exam-id>/<run-id>/` (git-ignored: plan.json, config.json, input/exam.md, calls/NNN-{prompt,reply}.txt + index.jsonl written per call, result.json, run.log, report); `--out DIR` puts the same files in DIR. The report is built by `pipeline/report_build.py` (input = the plan run dir only; no model call, no network; deterministic, byte-identical on rebuild) into `reports/<exam-id>/<run-id>/sheet/` (report.md, answers.md, metrics.json, report.json, optional pdf). `exam.py report PLAN_RUN [--view sheet|learn] [--no-pdf] [--report-id ID] [--out DIR]` rebuilds it (many reports per plan run; same id overwrites); `report RESULT.json --out DIR` still works. `exam.py plan-import DIR [--exam EXAM.md] [--exam-id ID] [--trace FILE...] [--ingest-cache DIR]` (no model call) turns an old run dir (result.json, optional run.log) into a plan run with `source: import`, `calls_captured: false` (calls/index.jsonl rows from run.log marked `reply: "not captured"`; old solve replies were never stored); symlinks are skipped; the exam text comes only from `--exam` or a result.json `exam.path` inside DIR (else WARN, "exam not imported"); `--trace FILE` (repeatable, <= 20 MB each) copies refine traces from anywhere; ids (`--exam-id`, `--report-id`, plan.json ids) allow only `[A-Za-z0-9._-]`, no leading dot or `..` (exit 2); it also copies the dir's `*.trace.json` and the ingest reply-cache dir (`DIR/../work/ingest/<hash>`, only when it is the single one, else pass `--ingest-cache`) into `ingest/` as raw AI output; the same dir + same result.json again prints `skipped`, exit 0; no result.json exits 2; `report` then rebuilds it. `solve` prints a 3-line metrics block and report.md gets `## Metrics`. `solve --pdf FILE [--max-image-pages N]` (TASK-059; FILE = PDF or ingest doc.json; N default 4, needs --pdf else exit 2) adds one page-image call for questions that refer to a figure/table missing from the text (never key pages); config.json gets `image_pdf`/`max_image_pages` only then; the call is captured in calls/ (index line `tag: image`, `pages`; no PNGs stored); result question `source` = text|image|text+image (report.md `- Source:`); metrics counts `image_checked`/`image_changed` and the metrics line show only for such runs; `--dry-run` prints the image prompt and estimate. Without `--pdf` behaviour is unchanged. compare exit 2 on different exam, 1 on a regression signal.
