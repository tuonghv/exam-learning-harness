## Commands

- `exam.py run-stats stats DIR | compare A B | trend | backfill DIR...` (TASK-056): run metrics from result.json + run.log; history `plans/run-history.jsonl` (`--history`; legacy `reports/` and `results/run-history.jsonl` still read), appended by `solve --real` or `solve --history`. `solve` without `--out` writes a plan run `plans/<exam-id>/<run-id>/` (git-ignored: plan.json, config.json, input/exam.md, calls/NNN-{prompt,reply}.txt + index.jsonl written per call, result.json, run.log, report); `--out DIR` puts the same files in DIR. The report is built by `pipeline/report_build.py` (input = the plan run dir only; no model call, no network; deterministic, byte-identical on rebuild) into `reports/<exam-id>/<run-id>/sheet/` (report.md, answers.md, metrics.json, report.json, optional pdf). `exam.py report PLAN_RUN [--view sheet|learn] [--no-pdf] [--report-id ID] [--out DIR]` rebuilds it (many reports per plan run; same id overwrites); `report RESULT.json --out DIR` still works. `exam.py plan-import DIR [--exam EXAM.md] [--exam-id ID] [--trace FILE...] [--ingest-cache DIR]` (no model call) turns an old run dir (result.json, optional run.log) into a plan run with `source: import`, `calls_captured: false` (calls/index.jsonl rows from run.log marked `reply: "not captured"`; old solve replies were never stored); symlinks are skipped; the exam text comes only from `--exam` or a result.json `exam.path` inside DIR (else WARN, "exam not imported"); `--trace FILE` (repeatable, <= 20 MB each) copies refine traces from anywhere; ids (`--exam-id`, `--report-id`, plan.json ids) allow only `[A-Za-z0-9._-]`, no leading dot or `..` (exit 2); it also copies the dir's `*.trace.json` and the ingest reply-cache dir (`DIR/../work/ingest/<hash>`, only when it is the single one, else pass `--ingest-cache`) into `ingest/` as raw AI output; the same dir + same result.json again prints `skipped`, exit 0; no result.json exits 2; `report` then rebuilds it. `solve` prints a 3-line metrics block and report.md gets `## Metrics`. `solve --pdf FILE [--max-image-pages N]` (TASK-059; FILE = PDF or ingest doc.json; N default 4, needs --pdf else exit 2) adds one page-image call for questions that refer to a figure/table missing from the text (never key pages); config.json gets `image_pdf`/`max_image_pages` only then; the call is captured in calls/ (index line `tag: image`, `pages`; no PNGs stored); result question `source` = text|image|text+image (report.md `- Source:`); metrics counts `image_checked`/`image_changed` and the metrics line show only for such runs; `--dry-run` prints the image prompt and estimate. Without `--pdf` behaviour is unchanged. TASK-061: `--image-scope flagged|declined|doubt` (default flagged = unchanged; needs --pdf) sends cut/marker-declined (declined) and doubtful answered ids (doubt, lowest page priority) to the same one image call; same answer adds finding `image_agrees` (never PASS); `--adjudicate` adds one text call for `image_differs` ids (status UNCERTAIN `needs_review: adjudicated`, call cap +1); result `run.image_scope` and metrics `image_scope`/`image_agrees`/`image_differs` only for such runs. compare exit 2 on different exam, 1 on a regression signal. TASK-063 `run-stats board [--history F] [--baseline RUN_ID|DIR] [--exam FILE] [--kind K] [--source solve|backfill|regset] [--review-pack F] [--json]` (free, no AI call, no key read): per exam kind (`subject/language/level` from result.json) coverage, quality (key = scorer `score{points,max}`, else QA proxy, else `quality unmeasured`), cost and delta vs the baseline (`--baseline`, else the previous run of the same `exam_sha256`) with verdict `better|same|regression|unmeasured`; `COVERAGE_UP_QUALITY_DOWN` when coverage rises and wrong answers rise beyond noise; exit 1 on a regression, 2 on error (different exam). History lines gain `kind`; `compute(..., quality=True)` adds a `quality` block (board only).
- Provenance sidecar (TASK-048): `exam.py ingest --exam-out E.md` also writes `E.md.assembly.json` (`{schema: "assembly/1", exam, questions: [{id, printed, source_pages, assembly_status complete|uncertain, validation_status passed|failed, reasons}]}`, one row per exam question; `source_pages` is `[]` on the text path (no per-question page); not written for an exam-format Markdown source); `api.assembly(doc, cfg)` shares its selection with `to_exam_text` (failed <=> `[Incomplete:` marker). `ingest-inspect` gets an `## Assembly` table; `solve`/`plan-import` copy the sidecar next to the exam to `input/assembly.json`. Dev prompts only: refine.md rule 12 (no running headers/footers; voids cached refine pages) and a `missing_text:` decline bullet in dev system.md (en, vi); release v1.0.0 untouched.
- `exam.py ingest-refine` (TASK-047): a cut last question is re-read whole by one window call over its pages (rule 11 of `prompts/dev/ingest/refine.md`, dev channel only, no release copy); flags `--no-window` (pre-47 bridge only), `--no-recover` (no pages outside `--pages`), `--cache DIR` (page reply cache, key = model + prompt + image hashes; `--real` only, mock runs never touch disk); `--dry-run` prints `pages P, windows planned W (native), calls <= ..., est cost`. `<out>.trace.json` rows: `{ok, cls, cost_usd, text, reason, page, pages, png_sha256, cached}` (separate from the solve plan-run calls/). `--mock FILE`: a JSON list is replayed in order, a JSON object maps the page label (`"8"`, window `"7-8"`) to a reply. Optional output fields: question `window`, refined `windows`, `recovered_pages`; absent when no question is cut.
- OCR route quality (TASK-051): scanned PDF pages are read by tesseract (`vie+eng` wanted; `tesseract --list-langs` must list `vie`). Text is rebuilt from char boxes (`OCR_GAP = 0.15`), running headers/footers are removed OCR-tolerantly, and a question touching an OCR page gets `ocr_doubt` = sorted kinds `glued` | `chars` | `furniture` | `lang_missing` (hard marker: `[Incomplete: missing_text ocr_doubt <kind>]`, sidecar `uncertain`, engine declines it; no AI fallback). `lang_missing`: `vie.traineddata` absent -> every OCR question marked, warning `ocr_language_missing` at level `error`; put `vie.traineddata` in `/usr/share/tesseract-ocr/<ver>/tessdata/` or `$TESSDATA_PREFIX` (or config `tessdata`), the engine never fetches it; the run still completes. Measurement helpers: `tests/unit/ocr_gap_sweep.py` (gap), `tests/unit/ocr_before_after.py [out.tsv]` (before/after real-error, unmarked-wrong, glued, false alarm; vie+eng, synthetic).
- Exam-kind data (TASK-062): `config/lang.json` (`{"extra": {code: {slot: [words]}}}`, words not regex; vi+en stay code literals, data only adds; slots question/group/range/intro/part/page/true/false/paragraph/figure/needs_text/scripts) read by `utils/langtable.py` for segment, refine, pdf page furniture + garble scripts, verdicts, refcheck. `config/subjects.json` optional `answer_shapes` (`tf4`, `number`) and `label`; `config/genexam_profiles.json` holds the gen-exams profiles (subject, prompt, qa_prompt, topics, check reply|mc4|mc, blind, exam_type, level, lang, instructions, grading_line); a bad profile is GenError `bad_profile`. Golden: `tests/unit/test_generality_golden.py`.
