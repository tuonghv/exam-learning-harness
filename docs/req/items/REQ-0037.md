## Requirement
WHEN the coordinator advances a TASK (DESIGN, IMPLEMENTING, UNIT_TESTED, VERIFIED, DONE), the workflow SHALL offer one deterministic command that sets the required task fields from a small spec, appends the phase-log entry, re-syncs the task view, steps the linked REQs through their gated statuses, runs workflow-check and commit-check, and stops with a clear message on the first failed gate, so no transition is hand-written in ad hoc Python. A skill SHALL document when and how to use it.
