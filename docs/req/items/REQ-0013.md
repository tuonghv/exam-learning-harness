## Requirement
WHEN development edits a prompt, the engine SHALL keep using the last released prompt version unless a dev run is explicitly requested; a release SHALL be an immutable, versioned snapshot chosen by config.

## Acceptance
- [x] AC1: prompts/dev/ is editable; prompts/releases/<version>/ is a frozen copy with a manifest (version, date, sha256 of each file)
- [x] AC2: engine default channel = release (current version in config/engine.json); `--channel dev` or `--prompt-version X` selects another, and the chosen version is written into result.json
- [x] AC3: a release script copies dev to a new version, refuses to overwrite an existing version, and a check fails if a released file's sha256 differs from its manifest
- [x] AC4: tests: default run never reads dev; editing dev leaves release output unchanged
