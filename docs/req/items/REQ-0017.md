## Requirement
WHEN a PDF is ingested, the PDF adapter SHALL inspect it (pages, size, text and image presence, password, corruption), extract native text with coordinates and Unicode (Vietnamese diacritics), flag pages with missing, short or suspicious text, run Tesseract (vie+eng) only on those pages, and render page images or crops (page and bbox recorded) only where text cannot carry the content, setting statuses native_text, ocr, mixed or needs_review with warnings.

## Acceptance
- [ ] AC1: a digital PDF with Vietnamese text ingests as native_text with correct diacritics, page numbers and bboxes
- [ ] AC2: a scanned PDF page uses OCR only for that page; native text is never replaced by OCR automatically; missing tesseract or vie data gives a structured warning or error
- [ ] AC3: a multi-column or multiple-choice layout keeps a conservative reading order; a table and a diagram page yield table data or a cropped asset reference with bbox
- [ ] AC4: password-protected, corrupted and empty PDFs give structured errors
- [ ] AC5: the original PDF is never modified; no claim of extraction accuracy beyond the heuristics reported
