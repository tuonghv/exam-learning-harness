## Requirement
WHEN a math exam page is ingested, the system SHALL store each question with its text, math in LaTeX (`$...$`, plain-text twin for the solver), option texts, figure refs, and a source trace (page, bbox, crop file, extraction route per field), and a `verification` record (status unverified|verified|needs_review|rejected, checks run, reasons), inside the existing canonical document `questions[]` (additive, schema_version stays readable); the original file and its sha256 remain the source of truth.
