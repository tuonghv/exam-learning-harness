## Requirement
WHEN a subject is solved, the system SHALL run a solve QA pass as a senior solver: each question is solved independently from the source (not from the engine output), disagreements and low-confidence items are adjudicated with a second independent read, and the result (answer, confidence, 1-3 line reasoning, verdict agrees / differs / flawed question) is merged into the review pack as a `QA:` line per question. The user reviews EXTRACTION fidelity and may read the QA solution; the user is NOT asked to decide answers (RAW-00159: the senior-solver QA covers correctness). Source: user RAW-00159.
