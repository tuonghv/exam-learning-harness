## Design
Gap analysis (inspector, 2026-10-30): no sheet today; answers only as `- Answer: D` inside each `## Question N` section (src/exam_engine/pipeline/reporter.py:64, build_markdown :47, write_reports :228). Data: result["questions"][i]["answer"] (A-D | null | "Open"), id is a string, subject = result["exam"]["subject"], N = len(questions). Gaps: no circled-letter map, no zero-pad (guard non-numeric id), null prints "none", sheet must exclude verdict/cost/explanations, tabs collapse in md2html so use a monospace fenced block, font coverage of Ⓐ-Ⓓ in PDF untested. Plan: pure `build_answer_sheet(result)` in reporter.py, called from build_markdown/write_reports; tests in tests/unit/test_exam_report.py with null-answer fixtures (work/dgnl-real Vietnamese/Science). One subject per run, so one sheet per result; a combined multi-subject sheet is out of scope.
