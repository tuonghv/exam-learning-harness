## Requirement
WHEN asked, the generator SHALL write DGNL-style English language items (grammar, vocabulary, short reading) with a letter key that has no code oracle, and SHALL accept an item only if two independent blind reviews (they see the question and options, never the key or the solution) both choose the key letter; items that fail go to `rejected/`.

## Acceptance
- [ ] AC1: `gen-exams --profile dgnl-en` (subject english) writes paired files that pass the format checker, with the blind double review; $0 mock tests (key not shown to the reviewers; one disagreeing reviewer rejects).
- [ ] AC2: manifest records `key_basis: 2 blind reviews` and `source: model knowledge, not an official exam`; the benchmark basis stays "key match" (never "verified by code").
- [ ] AC3: concept round with the user's go: 4 items under $0.5, benchmark and lessons, report with the items for the user to cross-check (language keys are opinions until a person reviews them).
- [ ] AC4: Vietnamese-language items (tieng Viet) are a later round, only after AC3 lessons.
