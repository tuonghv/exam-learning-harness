## Requirement
WHEN a DOCX is ingested, the DOCX adapter SHALL extract paragraphs, heading levels, tables and embedded image references into the same canonical document, preserving the original file; and the set SHALL ship with focused tests for the ten cases of the spec (synthetic fixtures), usage documentation and known limitations.

## Acceptance
- [ ] AC1: a DOCX with headings, paragraphs, a table and an image ingests to a valid canonical document and converts to an exam file
- [ ] AC2: tests exist for the ten cases of spec section 8 (digital, scanned, Vietnamese, math, table and diagram, multi-column, DOCX, Markdown, invalid input, backward compatibility); those needing a missing library or tesseract skip with a reason
- [ ] AC3: `docs/guide` explains how to process a PDF, DOCX or Markdown file and lists limitations and unresolved extraction risks
- [ ] AC4: the final report lists schema, interface, PDF strategy and dependencies, files, usage, test results and limitations
