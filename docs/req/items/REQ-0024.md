## Requirement
WHEN `solve` is given a document or question set with verification data, the engine SHALL run only questions whose status meets the configured minimum (`config/engine.json` `min_verification`, default `verified`, option `any` for legacy files), report the others as `skipped_unverified` with reasons in the result and report, and never solve a `rejected` question; exam-format files without verification data behave exactly as today.
