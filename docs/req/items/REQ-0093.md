## Requirement
WHEN a report kind in config/report_kinds.json has an `md` file, the registry SHALL also require a `pdf` of the same name, the writers/pack SHALL generate it from that md (md_to_pdf, no AI cost), and tools/check_report_pack.py SHALL fail when any md has no matching pdf, so a pdf is never missed (user, RAW-00263). Then the DGNL 2026 pack SHALL be rebuilt and re-checked, and the result reported.

## Acceptance
- [ ] AC1: registry rule `pdf_with_md` (or ext lists) so every kind with md lists pdf: answer-sheet and score-summary gain pdf; docs/guide/report-kinds.md equal to the registry.
- [ ] AC2: report-pack/write_reports produce <name>.pdf beside every <name>.md in the pack (answer-sheet, solution-report, score-summary, learning-report).
- [ ] AC3: check_report_pack fails when an md has no pdf (and when a pdf has no md); unit test for both.
- [ ] AC4: INDEX.md lists the new pdf files with kind and count; legacy folders unchanged.
- [ ] AC5: pack rebuilt at $0; checker passes; counts reported (md count = pdf count).
- [ ] AC6: no PDF renderer on the machine -> a clear failure naming the renderer (not a silent skip).
