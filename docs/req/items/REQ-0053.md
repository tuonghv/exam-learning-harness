## Requirement
WHEN the rule-based engine meets words it does not know (a wording or marker that begins a question, e.g. an unfamiliar question-start word) and cannot decide whether a line begins a question, begins a subject/section, or ends a question (an unfamiliar wording, a heading it has no pattern for, a passage/instruction line next to the options), the engine SHALL fall back to a cheap model (`claude -p` with Haiku) on a small window of lines around the uncertain spot, SHALL validate its reply deterministically, and SHALL use it only as a hint that feeds the existing gates (completeness check, numbering, decline), never as proof, with a cost cap and per-window cache. The rules stay the primary route (lightweight, free); the fallback covers wording the rules have not seen yet. Source: user RAW-00147.

- [ ] AC1: a deterministic uncertainty signal marks the lines/windows where rules disagree or have no pattern (candidate question starts, subject/section headings, end-of-question after the last option, passage vs option text); everything else never goes to the model
- [ ] AC2: the Haiku fallback classifies a window (labels: question_start, subject_start, section_start, question_end, passage, option_continuation, other) with a strict JSON reply validated by code (allowed labels, line indices inside the window, confidence); invalid reply -> no change plus warning; small context only (window of at most ~40 lines), batched per run
- [ ] AC3: the hint is applied only through existing gates and marked AI-origin in warnings/trace (never an independent verification), a disagreement with a strong rule signal keeps the rule; cost cap (`--max-cost-usd`), per-window cache by text hash + prompt hash + model, `--mock` and `--dry-run` supported, default off in unit tests
- [ ] AC4: tier-0 tests with mock replies cover: unknown heading wording, unfamiliar question-start marker, passage after option D, invalid JSON, out-of-window index, low confidence; measured on the guide fixtures (TASK-046) and the real DGNL text route: how many windows were uncertain, how many were changed by the model, cost per exam
