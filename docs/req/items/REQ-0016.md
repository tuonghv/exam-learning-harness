## Requirement
WHEN a source file is given, the system SHALL provide `ingest_document(path, config, meta)` returning a validated canonical document (schema_version, source, status, pages/sections, blocks with reading order, tables, asset refs, page and bbox, extraction method, warnings, optional question structure; source, extracted, normalized and AI-derived content kept apart) or a structured error, and SHALL convert it to the existing exam file format so `solve` runs unchanged. Markdown is the first adapter. Existing exam inputs keep working.

## Acceptance
- [ ] AC1: the current input contract and canonical schema v1 are documented in `docs/design`; `validate_document` rejects an invalid document with a list of errors
- [ ] AC2: a Markdown file (headings, lists, tables, code, math, local image refs resolved safely inside the file's folder) ingests to a valid canonical document and converts to an exam file that `solve --mock` accepts
- [ ] AC3: an existing `examples/**/input-*.md` passes through unchanged (backward compatible)
- [ ] AC4: unsupported format, empty file, invalid UTF-8 and a missing asset give structured errors; no subject logic or prompt in the ingest code
- [ ] AC5: unit tests cover the above, no external call
