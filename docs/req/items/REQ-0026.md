## Requirement
WHEN refined or extracted questions are produced, the system SHALL record the exam part (I multiple choice, II true/false sets, III short numeric) per question, SHALL NOT count a part heading as a question, and SHALL check answer format per part in verification: Part II = four true/false items, Part III = one number in the stated form; a failed format check never passes silently.

## Acceptance
- [x] AC1: refine drops a reply item whose text is only a part heading and sets `part` on each question from the heading order (seeded page-2 heading case in tests)
- [x] AC2: numbering is checked per part (restart at each part is not a gap)
- [x] AC3: verifier `_format` validates Part II (4 booleans) and Part III (single number) answers; Part I unchanged; solving engine output schema unchanged
- [x] AC4: unit tests ($0) cover each rule and a mutation per rule
