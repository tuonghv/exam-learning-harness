## Requirement
WHEN the solver is about to call a model for a question, the system SHALL look up a solve cache keyed by sha256(pinned full model ID + prompt text + question/data content) and, on a hit, reuse the stored answer at zero cost instead of calling the model.
WHEN a solve is requested for an exam that already has solved results, the system SHALL report that it is already solved (when, model, cost) and ask for confirmation before any paid re-solve; `--fresh` forces it.
IF the model is an unpinned alias (e.g. "sonnet"), THEN the system SHALL refuse it as a cache key and require a full versioned ID.
Eval keys SHALL never be part of the key or the cached input. Mock runs never read the disk cache.

## Acceptance
- [ ] AC1: same model ID + prompt + data twice -> second run makes 0 model calls, output identical, trace marks `cached`.
- [ ] AC2: changing the model ID, the prompt text, or the question data each causes a miss.
- [ ] AC3: an unpinned model alias is rejected with a clear message naming the full ID to use.
- [ ] AC4: solving an already-solved exam prints when/model/cost and exits without a paid call unless confirmed or `--fresh`.
- [ ] AC5: run metrics report cache hits and cost saved; corrupt cache entry counts as a miss.
- [ ] AC7: proof first on a small exam (a few questions, not a full big exam): solve once, re-run -> 0 calls, then scale (user, RAW-00242).
- [ ] AC8: the cache lives with that exam's own outputs (per input file); another exam never reads or writes it.
- [ ] AC6: reuse the existing `ingest/replycache.py` instead of a new cache.
