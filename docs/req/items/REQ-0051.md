## Requirement
WHEN the last question on a page is cut and continues on the next page, the engine SHALL NOT keep and stitch the fragment: it SHALL drop that open question from the page's result and extract it WHOLE in one call that sees both pages (the previous page image attached to the next page's call, "window with overlap"), within a bounded page and cost cap, so the question is read as one unit instead of being repaired afterwards (user, RAW-00154: be smart, do not debug stitching again and again); the existing `continues` bridge stays as the fallback when a question spans more pages than the window; a deterministic Python detector SHALL mark likely cut page boundaries so vision pages can be chosen without `--all-pages`; a page-extraction cache keyed by image hash, prompt hash and model SHALL avoid paying twice for the same page.
Parent: REQ-0045 (docs/design/phase-43-question-completeness-gate.md).
