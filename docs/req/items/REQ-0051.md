## Requirement
WHEN a refine run finds an orphan continuation or a cut question without its continuation, the engine SHALL re-extract the needed neighbouring page automatically within a bounded page and cost cap; a deterministic Python detector SHALL mark likely cut page boundaries so vision pages can be chosen without `--all-pages`; a page-extraction cache keyed by image hash, prompt hash and model SHALL avoid paying twice for the same page.
Parent: REQ-0045 (docs/design/phase-43-question-completeness-gate.md).
