## Requirement
<!-- Clear, testable statement in one language (English preferred). EARS: "WHEN <trigger>, the <system> SHALL <response>." -->
WHEN the user supplies official answers for a solved exam, the system SHALL (a) join answers with the saved run and produce, for every wrong answer and every flagged answer that is right, a cause record built from checks instead of opinion: stem and all options of the prompt compared with the PDF text layer of the source pages (extraction mismatch), shared passage and sibling context actually present in the prompt (context not delivered), reply path (malformed/retry/self-correction, image-only source, text vs image disagreement), the solver's quoted evidence found in the prompt, and a free independent recomputation hint; (b) report accuracy before and after each engine fix on a HELD-OUT exam (learn from one sample, measure on the other), because a fix tuned on the same exam overstates the gain; (c) keep answer lists out of git and out of every solver input.


## Acceptance
<!-- Each item objectively verifiable. VERIFIED requires every box ticked. -->
- [x] AC1: `run-stats explain RESULT_DIR --exam FILE --key FILE --pdf FILE` (free, no AI) writes a cause table (TSV, numbers only) with the automatic checks above; replay on 2026 run 3 and 2025 reproduces the manual root causes (107, 117, 59 engine paths; English malformed path; Science 111 false flag)
- [x] AC2: parse/context checks have tests on synthetic cases (stem truncated, option missing, passage absent from prompt, quote not in prompt) and never read the key outside scoring
- [x] AC3: held-out gain table: for each engine change, accuracy on the learn exam and on the other exam, before and after, with Wilson intervals and a stated caveat when n of changed answers is small
