## Requirement
<!-- Clear, testable statement in one language (English preferred). EARS: "WHEN <trigger>, the <system> SHALL <response>." -->
The engine SHALL NOT contain rules keyed to one exam (DGNL names, fixed subjects, question numbers, page numbers, a specific PDF layout); every behaviour is driven by generic signals in the data (headings, groups, cuts, figure refs, OCR doubt) or per-exam config, so a new exam kind needs config and data, not code. New design docs state how the change generalises.
