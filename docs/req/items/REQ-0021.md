## Requirement
WHERE extraction is flagged unreliable (math_possible, missing_text, bad numbering) and the user passes `--refine`, the system SHALL send only the exam-part page images (never detected answer pages) to the existing `claude -p` integration with a fixed prompt (model sonnet by default) that returns our standard question JSON (id, text, options, figure refs, plain-text math per the solver rules); the reply SHALL be stored as `origin: ai` blocks in a separate `refined` field, validated by code (schema, consecutive numbering, option count, similarity to the OCR/native text, each question traced to a page), and SHALL never overwrite source or extracted content; any mismatch is a warning for human review.

## Acceptance
- [ ] AC1: `ingest --refine` is off by default; `--dry-run` prints the number of calls, the page list and the cap before any call; a real run needs the user's go (cost gate) and uses `claude -p` with stream-json image blocks, tools off, empty cwd
- [ ] AC2: only pages in the selected exam range and flagged unreliable are sent; pages detected as an answer guide are refused unless `--allow-key-pages` (key-leak guard)
- [ ] AC3: the reply is validated by code and stored under `refined` with origin ai; source and extracted blocks are unchanged (hash equal before and after); invalid JSON or schema errors give one retry then a structured error
- [ ] AC4: each refined question reports a similarity score against the OCR/native text and a `needs_review` flag below a threshold; no accuracy claim without evidence
- [ ] AC5: tests use a mock reply ($0); a real benchmark on the trial PDF pages 1-4 compares OCR-only, refined, and the answer-guide numbering, reported honestly after the user's go

## Open questions
- [x] Q1: Which interface: the Anthropic API directly or the existing `claude -p`? Recommended: the existing `claude -p` with model sonnet. Why: one Claude integration (no API key handling, no new dependency or billing path), same cost gate, isolation and mock tests already exist; the raw API adds a second pipeline, which the spec forbids. -> accepted as recommended: existing claude -p, model sonnet (user, RAW-00062, 2026-10-29)
- [x] Q2: Scope of the refine: Recommended: only flagged exam pages, one call per page (about 4 calls for the trial PDF), default off, and the result is a reviewable suggestion, not a replacement. Why: deterministic extraction stays the base (spec), cost stays small, and an AI reconstruction can hallucinate formulas so it must be compared and reviewed. -> accepted as recommended: flagged exam pages only, one call per page, suggestion not replacement (user, RAW-00062, 2026-10-29)
- [x] Q3: Should the solver prefer the page image over refined text for math? Recommended: yes, the solve step receives the page image plus the extracted text, refined text only as a hint. Why: the image is the authoritative source. -> accepted as recommended: solver gets page image plus extracted text; refined text only a hint (user, RAW-00062, 2026-10-29)
