## Requirement
WHEN the solver builds a prompt for a question, the system SHALL classify it by its group shape and choose the solve shape: (a) INDEPENDENT (group guide only, e.g. `Questions 31-35: Choose a suitable word...`): each question carries guide + own stem and is solved alone; (b) PASSAGE GROUP (guide + shared passage, e.g. `Questions 46-52: Read the passage carefully`): each question carries the full passage (never a fragment) so e.g. `Câu 46` is answered from the content; (c) DEPENDENT (a question refers to another question's answer): the dependency is stated and the sibling answer is passed in. Applies to every subject, not only English. Builds on REQ-0057 four-level format (guide/passage levels).


## Acceptance

- [x] AC1: group kind (independent / passage / dependent) is derived deterministically from guide + passage levels (REQ-0057), per subject-agnostic rules; unknown shape -> treated as independent with a warning
- [x] AC2: independent questions are solved one per call or batched without shared content; golden: English cloze 31-35 prompts contain guide + own stem only
- [x] AC3: passage-group questions always include the full shared passage; golden: Câu 46-52 prompts each contain the passage once; a missing passage is declined (missing_text), never solved from a fragment
- [x] AC4: dependent questions (refer to another question's answer) are solved after their sibling, answer passed in; cycle or missing sibling -> decline with reason
- [x] AC5: design doc states why this shape is best (accuracy vs cost: passage tokens repeated vs one call per group) and covers non-English subjects; tests-first on 2-page slices
