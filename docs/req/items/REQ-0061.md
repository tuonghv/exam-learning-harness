## Requirement
WHEN a task reaches VERIFIED or DONE, the system SHALL place everything the user needs to cross-check the result in committed, fixed paths under docs/ (design in docs/design, report in docs/report, evidence summary in docs/report/evidence/TASK-NNN/ as small text files: test output, recount TSV, metrics, comparison), never only under work/ (agent scratch, git-ignored); the report links each evidence file; one index file lists the paths per task and per kind.


## Acceptance
- [x] AC5: solve-exam OUTPUT (result.json, report, run.log, metrics, run history, review packs) is never git-tracked: `exam.py solve` without `--out` writes to ./reports/<exam-id>/<run-id>/ (git-ignored), history moves to ./reports/run-history.jsonl, ./plans/ (git-ignored) holds per-exam solve plans; solving many exams never grows the repo (test: after a solve, `git status --porcelain` is empty)
