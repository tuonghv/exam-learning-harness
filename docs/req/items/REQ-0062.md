## Requirement
WHEN an exam is solved, the system SHALL store everything the run needs and produced in a PLAN directory plans/<exam-id>/<plan-run-id>/ (git-ignored): the config used, the input (exam text and its provenance), and the raw AI replies (prompts and raw outputs per call, including retry/QA), plus the parsed result.json. WHEN a report is built, the system SHALL read only a plan run and write reports/<exam-id>/<plan-run-id>/<report-id>/ with a deterministic report engine and no AI call and no network; many reports may exist per plan run and many plan runs per exam; rebuilding a report after a report-engine change SHALL NOT require re-running the plan. Builds on REQ-0060 (metrics) and REQ-0061 (output never tracked).
