## Requirement
<!-- Clear, testable statement in one language (English preferred). EARS: "WHEN <trigger>, the <system> SHALL <response>." -->
WHEN any session or role runs a recursive delete (rm -r/-rf, rmdir, find -delete, git clean, shutil.rmtree via python -c), the guard SHALL allow it only for targets proven inside work/, the session scratchpad or /tmp, and SHALL deny it for the repo root, its parents, home, /, bare or empty variable expansions, root-level globs, and plans/ reports/ input/ results/; work/ cleanup SHALL go through one safe script (.claude/scripts/clean-work.sh, realpath-checked); and a loss SHALL be recoverable: commits auto-pushed (TASK-149) and ignored outputs in a verified backup refreshed after each paid run.

## Acceptance
<!-- Each item objectively verifiable. VERIFIED requires every box ticked. -->
- [x] AC1: PreToolUse guard (all sessions + roles) allows deletes strictly inside the repo or /tmp (RAW-00380) and denies the unrecoverable ones: repo root/parents/home//, bare globs over the repo root or /tmp, plans/ reports/ input/ results/ .git, recursive deletes outside the repo and /tmp or with an unresolved `$VAR`/xargs/no target, `git clean -x/-X` or without a path
- [x] AC2: `.claude/scripts/clean-work.sh <TASK-NNN|work/...>` deletes only below work/ (realpath, no symlink escape); roles' instructions point to it
- [x] AC3: tests: the incident shapes (empty var, `cd work/X && rm -rf ../..`, `rm -rf ./*`, `find . -delete`, python rmtree, git clean -fdx) denied; work/ and scratchpad deletes allowed
- [x] AC4: recovery: the post-commit hook starts `exam backup` in the background whenever plans/ or input/ is newer than the newest backup (ignored outputs; AUTO_BACKUP=0 off), and the feature branch is auto-pushed (TASK-149)
