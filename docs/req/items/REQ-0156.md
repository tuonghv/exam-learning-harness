## Requirement
<!-- Clear, testable statement in one language (English preferred). EARS: "WHEN <trigger>, the <system> SHALL <response>." -->
WHEN any session or role runs a recursive delete (rm -r/-rf, rmdir, find -delete, git clean, shutil.rmtree via python -c), the guard SHALL allow it only for targets proven inside work/, the session scratchpad or /tmp, and SHALL deny it for the repo root, its parents, home, /, bare or empty variable expansions, root-level globs, and plans/ reports/ input/ results/; work/ cleanup SHALL go through one safe script (.claude/scripts/clean-work.sh, realpath-checked); and a loss SHALL be recoverable: commits auto-pushed (TASK-149) and ignored outputs in a verified backup refreshed after each paid run.

## Acceptance

- [ ] AC2: `.claude/scripts/clean-work.sh <TASK-NNN|work/...>` deletes only below work/ (realpath, no symlink escape); roles' instructions point to it
- [ ] AC3: tests: the incident shapes (empty var, `cd work/X && rm -rf ../..`, `rm -rf ./*`, `find . -delete`, python rmtree, git clean -fdx) denied; work/ and scratchpad deletes allowed
