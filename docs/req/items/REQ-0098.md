## Requirement
WHEN the engine writes a plan, it SHALL put it under `plans/<exam>/<line>/runs/<plan-run-id>/` where `<line>` names a line of work on that exam (default `main`; others like `fix_abc`, `noise`, `v2`), so one exam folder holds all its lines instead of many sibling folders such as `plans/dgnl2025-fix`, `plans/dgnl2025-fix2`, `plans/dgnl2025-noise`; every line has its own `runs/`. A `--line NAME` option on solve selects the line. The old folders SHALL be converted into this structure by a safe, reversible migration (user, RAW-00276: "you can convert old to this structure is okie"; it replaces the earlier "leave legacy in place" answer for plans).

## Acceptance
- [ ] AC1: `exam solve --line fix_abc` writes `plans/<exam>/fix_abc/runs/<id>/`; without `--line` it writes `plans/<exam>/main/runs/<id>/`; the resolver (runlayout) reads old, REQ-0095 and the new layout.
- [ ] AC2: `exam plans-migrate --dry-run` prints the full move table (old path -> new path, line, run id from plan.json time, subject) and the references it will rewrite; nothing is changed; `--apply` makes a backup archive first (outside plans/, size checked), moves with `os.rename` only inside plans/, writes `plans/MIGRATION.json` (old->new for every move) and is idempotent; `--undo` restores from that manifest.
- [ ] AC3: references to moved paths keep working: the 158-line `plans/run-history.jsonl` stores 50 absolute plan paths: the migration rewrites them (original kept as `.bak`) or the resolver maps old paths through MIGRATION.json; reports' `run.json` plan links and `plans/*/INDEX.md` likewise.
- [ ] AC4: name mapping is an explicit reviewed map (`config/plans_migration.json` or the dry-run table approved by the user), not a blind split on `-`; non-exam folders (confidence, crosssolve-070, regset, trial-image, dgnl-retry, dgnl-window, cacheproof-en, input-001) are listed with a proposed target or `keep`.
- [ ] AC5: the solve cache path and `last_solved` keep working per exam across lines (see Q2); `run-list EXAM` groups runs by line and shows the line column.
- [ ] AC6: tests on a tmp tree (dry-run, apply, undo, idempotence, history rewrite), a real dry-run on plans/ reviewed by the user BEFORE --apply, QA recount of file counts and sizes before/after (equal), `run-list` before/after identical rows.
