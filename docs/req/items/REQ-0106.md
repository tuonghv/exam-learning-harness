## Requirement
<!-- Clear, testable statement in one language (English preferred). EARS: "WHEN <trigger>, the <system> SHALL <response>." -->
WHEN a report is built (single plan or multi-subject pack), the engine SHALL by default write the student-facing kind `solution_public-report` (<exam>_<subject>_solution_public-report_<run>.md + pdf): per question the text, options, a highlighted 'Đáp án: X' and the steps, with no status, doubt, evidence, score, check, QA or error lines. WHEN a multi-subject pack is built (report-pack / publish), the engine SHALL NOT write per-subject human reports (answer-sheet, solution-report, solution_public-report); it SHALL write only the `all` reports (solution-report, solution_public-report, answer-table, score files) plus per-subject data files (metrics, result-data, run-log).
