## Requirement
WHEN the engine writes reports, it SHALL name each file by kind as `<exam>_<subject>_<kind>_<run>.<ext>` (kinds: answer-sheet, solution-report, learning-report, answer-table, score-vs-key, score-summary, metrics, result-data, run-log) instead of the generic `report.md` / `answers.md`, and SHALL write one `INDEX.md` per exam folder that lists every report file with its kind, what it contains and its count, so the user can see how many reports exist and cross-check each (user, RAW-00255).

## Acceptance
- [ ] AC1: a solve/report run writes only standard names; no bare `report.md`/`answers.md` remain in new output.
- [ ] AC2: each exam folder has an `INDEX.md` listing every file, kind, description and totals per kind.
- [ ] AC3: the kind list and name pattern are documented once (docs/guide) and used by report_build, run-stats and the scorer.
- [ ] AC4: old runs keep working: readers accept old and new names; the old folders are not renamed in place.
- [ ] AC5: a unit test fails when a report file is written with a non-standard name.

- [ ] AC6: whenever a report format or name changes, the reply says so: old name/format -> new name/format, which is current, and what to cross-check (user, RAW-00256); `docs/report/INDEX` or the exam INDEX.md marks superseded formats (e.g. reports/dhqg2024/solutions.* from 2026-11-05 is superseded by reports/dhqg2024-t81/ALL-120/report.*).
- [ ] AC7: solution-report = hybrid (user asked for a factor comparison, RAW-00257): per question show question text and options (as old solutions.md), then answer, status, doubt in words (no raw JSON), accented Vietnamese steps (as new report.md), grouped under one heading per subject; measured on dhqg2024: old 120/120 with question+options, 112 raw-JSON doubt lines, 17 mostly-unaccented solutions; new 0/120 with question+options, 0 raw JSON, 2 mostly-unaccented, status on every question.

## Open questions
- [ ] Q1: Keep the old names too for one release (compat) or switch cleanly? -> recommend (best): switch cleanly for new runs, readers accept both for old runs, per AC4.
- [ ] Q2: Include the run id (`run-<timestamp>`) in every name, or only in the folder name? -> recommend (best): short run id in the name, so a file moved alone is still identifiable.
